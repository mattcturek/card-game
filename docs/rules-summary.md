## Overview

An RPG card game on a shared hex board. Players race to finish a **secret mission** while trying to stop each other. Tone: Star Trek TNG capability crossed with Firefly frontier grit.

## Setup

1. Lay out the hex board over a **Milky Way (from Earth)** background.
2. Each player: ship on **center**, **20 HP**, **20 AP**.
3. Each player draws one secret **mission** card.
4. Shuffle **Tier 1 / 2 / 3 Event** decks (**10** each).

## Win / lose

- **Win:** first to complete their secret mission.
- **Lose:** **HP ≤ 0** (HP does not regenerate).

## HP & AP

- **AP** = attack power; deal AP damage, then spend **1 AP**; cannot Attack at **0 AP**.
- **AP regen:** +1 every **2 dice rolls**.



## Turn structure

- Turns **alternate**. **2 actions** per turn: **Move**, **Scan**, **Attack**.
- **Move:** d6 → **even = 2 spaces**, **odd = 1**; you may skip moving. Land on 0 = no Event; 1/2/3 = that Tier Event.
- **Scan:** your tile + all adjacent; **required before Attack**.
- **Attack:** ships/players on your tile or adjacent (after Scan); spend 1 AP.
- **Interrupts:** play anytime; mixed into main Event decks; card list later.

## Tile numbers & decks

Every hex shows **0–3**.

| Number | Draw |
|--------|------|
| **0** | Nothing |
| **1** | **Tier 1 Event** |
| **2** | **Tier 2 Event** |
| **3** | **Tier 3 Event** |


## Missions

Each mission card points you to board location(s). You must maneuver there and resolve the objective (exact resolve steps TBD).

| Mission | Destination tiles |
|---------|-------------------|
| Silent Relay at Station 9 | Cylinder station with solar panels — **corner** of the board |
| The Cold Cargo Run | **Pickup** + **Dropoff** (card names both) |
| Ghost Ship on the Drift | Derelict ship (1 tile) near a **gas giant** planet |
| Blackout at Helios Refinery | One **spaceship / refinery** tile |
| The Parley on Red Dust | **Red Dust** planet |

Complications on each card add risk once you engage the location.
