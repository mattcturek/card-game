# Card Types

Last updated: 2026-11-26 (America/Chicago)

## Card layout (locked)

Magic: The Gathering–style frame. **Canonical style reference:** [Dockmaster’s Tip](/cursor/stores/self/media/cards/card-t1-dockmasters-tip.jpg)

1. **Top half** — artwork / image  
2. **Middle** — card type line (e.g. Tier 1 Event, Mission, Hero, Ship, Interrupt)  
3. **Bottom box** — rules text / actions the card lets you take  

All future cards match this frame’s look (borders, type placement, text box).
  

## Starting draws (current streamlined rules)

- **1 Ship** from Ship Deck
- **1 Hero** from Hero Deck
- **1 Mission** from Mission Deck (secret)

## Card type list

| Type | Role |
|------|------|
| **Mission** | Secret objective / win condition (Mission Deck) |
| **Hero** | Character (Hero Deck) |
| **Ship** | Vessel (Ship Deck) |
| **Tier 1 Event** | Mild events (prior design; not in this streamlined pass) |
| **Tier 2 Event** | Harder events |
| **Tier 3 Event** | Hardest events |
| **Interrupt** | Play anytime; mixed into events (prior design) |
