# Card Game — Project Context

Last updated: 2026-11-26 (America/Chicago)

## Goal

Build an RPG card game with alternating turns. Each player takes a turn, with interrupt opportunities that can break or respond mid-sequence.

## Setting & ship tone

The ship is a cross between **Star Trek: The Next Generation** and **Firefly**:

- **TNG**: exploratory starship, capable crew, mission-driven, optimistic sci-fi
- **Firefly**: lived-in vessel, found-family crew, scrappy independence, frontier feel

Tone sits between polished Federation idealism and dusty frontier grit — a capable ship with character, crewed by people who make it work.

## Core rules (locked so far)

Quick read: [rules summary](rules-summary.md). Living drafts: [rules](rules.md), [missions](missions.md), [board](board.md).


- Random **secret objective** per player (primary mission).
- Players race to finish their own goal while trying to stop others.
- **First to complete their objective wins.**
- Shared **hex board**; each player’s ship token starts at center; roll a die to move; landing on a tile triggers its image/effect.
- Mission cards point to **locations on the board**; those tiles are placed from the mission set first, then the rest of the board is filled.
