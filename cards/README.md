# Event cards

Each tier folder holds card art JPGs. Rules text is in [`../docs/decks-60.md`](../docs/decks-60.md). Index: [`../docs/card-art-index.md`](../docs/card-art-index.md).

```
cards/
  tier-1/   # 20 Tier 1 Event arts
  tier-2/   # 20 Tier 2 Event arts
  tier-3/   # 20 Tier 3 Event arts
```

Filenames: `card-t{N}-{##}-{slug}.jpg` match the locked deck list.
